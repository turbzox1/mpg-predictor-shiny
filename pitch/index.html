MPG Predictor

A quick way to see how weight, power and gearbox affect fuel efficiency

Piyush Patni
Developing Data Products, Course Project

The problem

When people shop for a car, they usually compare horsepower and price, but its hard to get a feel for how much those choices cost at the pump.

  • Is a heavier car really that much worse?
  • How much efficiency do you give up for an extra 50 horsepower?
  • Does a manual gearbox still make a difference?

MPG Predictor answers these in seconds: move three inputs and watch the predicted miles per gallon change.

How it works

The app fits a linear regression on Rs built-in mtcars data (32 cars) using weight, horsepower and transmission:

fit <- lm(mpg ~ wt + hp + am, data = mtcars)
round(coef(fit), 3)

## (Intercept)          wt          hp          am 
##      34.003      -2.879      -0.037       2.084

Each extra 1000 lbs costs about 2.9 MPG, and each extra 100 hp costs about 3.7 MPG.

A live example

This is the same calculation the app server runs when you set the sliders to a 3,200 lb, 150 hp car with a manual gearbox:

myCar <- data.frame(wt = 3.2, hp = 150, am = 1)
round(predict(fit, myCar, interval = "prediction"), 1)

##    fit  lwr  upr
## 1 21.3 15.7 26.8

So the app reports about 21.3 MPG, along with a 95% prediction interval so users know how uncertain the estimate is.

Try it

  • Inputs: sliders for weight and horsepower, a radio button for transmission, a checkbox to show similar cars
  • Simple: three inputs, instant results, no statistics knowledge needed
  • Honest: shows a prediction interval, not just a single number
  • Documented: a built-in How-to-use tab walks new users through it
